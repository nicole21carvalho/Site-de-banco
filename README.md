# 🏦 Banco Tech.In.Fin

Protótipo de site de banco digital feito com **HTML e CSS**: páginas de entrada, cadastro, dashboard e formulários dos principais serviços bancários.

🔗 **[Abrir o site](https://nicole21carvalho.github.io/Site-de-banco/)**

## ✨ Páginas

- 🚪 **Entrada:** escolha entre conta de cliente e de funcionário
- 📝 **Cadastro** de nova conta, com página de confirmação
- 📊 **Dashboard** com acesso aos serviços e à central de ajuda
- 💸 **Formulários de serviços:** Pix, transferência, investimentos, empréstimos, financiamentos e previdência

## 🛠️ Tecnologias

HTML · CSS

## 🚀 Como executar

Abra o [site publicado](https://nicole21carvalho.github.io/Site-de-banco/) ou baixe o repositório e abra a `Página de entrada0.html` no navegador.
